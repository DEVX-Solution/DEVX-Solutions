# DevX Solutions

Projeto convertido do HTML enviado para **React + Node.js + Express + Tailwind CSS**.

## Rodar o projeto

```bash
npm run install-all
npm run dev
```

Frontend:
```txt
http://localhost:5173
```

Backend:
```txt
http://localhost:5000
```

## Funcionalidades

- Navegação com scroll suave
- Menu responsivo
- Botões de planos abrindo WhatsApp com mensagem personalizada
- Cards com hover
- Contato por e-mail, WhatsApp e localização
- Emojis trocados por ícones SVG/imagens via Lucide React
- Backend Express com rotas `/api/health`, `/api/contact` e `/api/lead`

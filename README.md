# DEVX Solutions

Site inspirado no mockup enviado, feito com:

- React
- Node.js
- Express
- Tailwind CSS
- Vite

## Como rodar

```bash
npm run install-all
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:5000

## Build

```bash
cd client
npm run build
cd ..
npm start
```
